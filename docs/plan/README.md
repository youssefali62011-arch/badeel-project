# Project plan

`Badeel_Project_Plan.pdf` is the plan for both semesters: the work completed, the tasks per track with owners, the milestones, the evaluation plan and the research paper plan.

To update it, edit `build_plan.py` (statuses, dates, tables), then:

    python docs/plan/build_plan.py          # writes Badeel_Project_Plan.html
    # print the HTML to PDF (A4, background graphics on) from Chrome, or with Playwright

Update the plan at every milestone.
